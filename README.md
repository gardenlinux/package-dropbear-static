# package-dropbear-static

- dropbear is a SSH 2 server and client designed to be small enough to be used in small memory environments, while still being functional and secure enough for general use.

- The idea was to ship dropbear with tests-ng instead of relying on the OpenSSH server in our images. The idea is discarded for now.

- This package was a customised package which extracted static binaries of `dropbear` from `.deb` packages in the release, and was customised for Garden Linux

- Archived in Week 2025-09-25
